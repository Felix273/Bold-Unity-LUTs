# Bold Unity — Cinematic LUTs

Cinematic color-grading LUTs for Premiere Pro & DaVinci Resolve.

Built with Vite, React 19, TypeScript, and Tailwind CSS v4.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Status

Rebuilding from a scaffold export — auth, storefront, and payments are being
implemented fresh.
